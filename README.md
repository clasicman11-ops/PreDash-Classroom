# PreDash Classroom · 키움증권 투자 대시보드

선생님의 PreDash와 분리한 수업용 코드입니다. 개인 계좌를 조회하고 시장·기업·수급·차트를 보면서 나만의 투자 화면을 실습합니다. 실제 주문 전송 기능은 없습니다.

## 수강생 시작 순서

1. 이 저장소의 Fork 버튼 → 본인 계정에 복사합니다.
2. Streamlit Community Cloud에서 본인 Fork의 main / app.py를 배포합니다.
3. 앱 Settings → Secrets에 APP_PASSWORD를 설정합니다. 기업 분석용 DART·공공데이터·KRX·관세청 키는 앱의 08 데이터 연결 화면에서 현재 세션에 입력하거나 본인 앱의 Streamlit Secrets에 설정할 수 있습니다.
4. 앱 로그인 → 08 데이터 연결 → 앱 서버 IP 확인 → 키움 REST API에 허용 IP 등록 → 모의투자 조회 또는 실전 조회 선택 → 해당 환경의 App Key·App Secret 입력 → 연결 확인.
5. 관심종목·투자 근거·대시보드를 자신의 기획에 맞춰 수정합니다.

키움 실전·모의 키를 각각 연결할 수 있습니다. 계좌는 키에 연결되어 있으므로 계좌번호를 따로 입력하지 않습니다. 화면에 직접 입력한 키는 현재 접속에서만 사용합니다. 본인 전용 앱에서는 Streamlit Secrets에 키움 실전·모의 키를 선택적으로 저장해 로그인 후 자동으로 불러올 수 있습니다. 로그아웃 시 접속 중의 키·토큰·조회 결과를 지우며, Secrets 설정은 남습니다. 앱 비밀번호를 아는 사람은 저장된 계좌를 조회할 수 있습니다. 실제 키는 GitHub에 올리지 마세요. 연결 변경·해제 시 이전 조회 결과와 실습 자료를 지우므로 필요한 기록은 먼저 백업하세요. 서버가 키를 처리하므로 각자 관리하는 앱에서 사용하세요.

Streamlit Cloud의 발신 IP는 변경될 수 있습니다. 키움 연결 조건, 기능별 API와 확인할 제한은 [키움 연결 안내](docs/KIWOOM.md)를 확인하세요.

## 재접속 시 설정과 목록 유지

앱 화면 입력은 Streamlit 세션이 끝나면 초기화됩니다. API 키를 유지하려면 [share.streamlit.io](https://share.streamlit.io/)에서 해당 앱 옆 ⋮ → Settings → Secrets → Save를 사용하세요. 기존 `APP_PASSWORD`와 공공 API 설정은 유지하고, 필요한 키움 항목만 추가합니다.

```toml
KIWOOM_DEFAULT_MODE = "real" # 모의를 기본으로 쓰려면 "demo"
KIWOOM_REAL_APP_KEY = "내 실전 App Key"
KIWOOM_REAL_APP_SECRET = "내 실전 App Secret"
KIWOOM_DEMO_APP_KEY = "내 모의 App Key"
KIWOOM_DEMO_APP_SECRET = "내 모의 App Secret"
```

각 환경의 두 키가 모두 있어야 설정을 불러옵니다. 기본 환경을 생략하면 모의를 우선합니다. 저장 설정과 인증 성공은 구분하며 **키움 연결 진단**으로 실제 연결을 확인하세요. **연결 해제**는 현재 접속에만 적용됩니다. 다음 로그인에서도 제거하려면 Secrets의 해당 키를 삭제하세요. 로그인 비밀번호는 재접속 때 다시 입력합니다.

관심종목은 최대 **20개** 등록할 수 있으며 코드·이름·직접 지정한 분류·섹터명을 브라우저에 자동 저장합니다. **저장 완료** 표시 후 닫으면 같은 앱 주소·브라우저·프로필에서 재접속 시 목록을 복원합니다. 다른 기기·브라우저와 자동 동기화하지 않으며, 시크릿 모드·사이트 데이터 삭제·앱 주소 변경 시 저장 목록이 없어질 수 있습니다. 기존 **종목 목록 백업 / 복원**으로 이동·복구할 수 있습니다. 브라우저 저장이 차단되면 화면에 알려줍니다. API 키·토큰·계좌번호·잔고·시세·실적은 브라우저에 저장하지 않습니다. 재접속 후 조회 자료는 새로고침하세요.

종목코드 직접 추가·목록 백업·삭제는 공공 API 키 없이도 가능합니다. 관심종목을 담은 기존 `?watch=` 주소로 접속하면 그 주소의 목록을 적용합니다. 여러 탭에서 편집하면 마지막으로 저장한 목록이 다음 접속에 적용됩니다. 로그아웃해도 브라우저 목록은 남으며 **관심종목 목록 비우기**로 삭제합니다. 모의 매매 연습 기록·섹터 조사 등 다른 접속 자료는 기존처럼 백업이 필요합니다.


### 관심종목 분류와 선택 조회 (UI 2.11)

- **분류 · 섹터 관리**에서 종목을 선택하고 보유종목 / 매수 관찰 / 섹터 관심과 섹터명을 직접 지정합니다. 기존 목록은 매수 관찰로 표시합니다. 분류와 섹터는 재접속·백업·복원 시 함께 유지됩니다. 보유종목 분류는 사용자 지정이며 계좌의 실제 보유 여부를 자동 판정하지 않습니다.
- **표시할 분류 / 표시할 섹터**로 목록을 좁히고 **조회할 종목 선택 → 선택 종목 조회**를 누릅니다. 처음에는 표시 목록 중 최대 5개를 선택하며, **현재 분류 모두 선택**으로 원하는 분류 전체를 조회할 수 있습니다. 선택하지 않은 종목의 기존 조회 결과는 유지합니다. 목록을 열거나 필터를 바꾸는 것만으로 시세·실적·수급을 조회하지 않습니다.
- 같은 로그인 접속 안에서 **최근 15분간 오류 없이 조회한 종목 자료**를 재사용합니다. **최신 자료 다시 조회**를 체크하면 선택한 종목만 다시 요청합니다. 오류·부분 실패 자료는 다음 요청에서 재조회하며, 조회 시각과 데이터 기준일은 화면에 유지합니다.
- 재사용 자료는 다른 사용자와 공유하거나 브라우저에 저장하지 않습니다. 키·실전/모의 환경 변경, 한국시간 날짜 변경 및 18시 데이터 기준 전환 후에는 재사용하지 않으며 연결 변경·해제·로그아웃 시 조회 메모리를 지웁니다. 실제 조회 시간과 호출 횟수는 공급기관·연속조회·실패 재시도에 따라 달라집니다.

검증: `python -m unittest discover -p 'tests_*.py'`, `node tests_watch_storage.mjs` (브라우저 저장 통신 로직).
