# 키움증권 연결 안내

확인일: 2026-10-02. 이 앱은 **키움 REST API**를 사용합니다. Windows의 OpenAPI+ / OCX 방식은 사용하지 않습니다.

## 설정

1. Streamlit 앱 Settings → Secrets에 `APP_PASSWORD`를 설정합니다. 기존 OpenDART·공공데이터·KRX·관세청 키는 그대로 사용합니다.
2. 키움 REST API의 실전 및 모의 계좌별로 발급한 App Key·App Secret을 준비합니다. 각 키에 계좌가 연결되어 있으므로 앱에 계좌번호나 계좌 비밀번호를 입력하지 않습니다.
3. 앱에 로그인하고 **08 데이터 연결 → 앱 서버 IP 확인**을 누릅니다. 키움 API의 허용 IP에는 앱 서버의 발신 IP를 등록해야 합니다. 사용자 PC의 IP와 다릅니다.
4. **연결할 환경**에서 모의투자 조회 또는 실전 조회를 고르고 해당 환경의 키를 입력합니다. **키움 연결 확인**은 잔고를 조회해 연결을 검증합니다.
5. 두 환경을 모두 연결할 수 있습니다. **일반 화면에서 사용할 계좌**를 명시적으로 선택합니다. 모의투자 메뉴는 모의 키만 사용합니다. 모의 API가 지원되지 않아도 실전 키로 자동 전환하지 않습니다.

증권사 키는 GitHub·Streamlit Secrets·파일·전역 캐시에 저장하지 않습니다. 현재 사용자의 Streamlit 세션 메모리에서만 사용합니다. 로그아웃하면 두 환경의 키와 자료를 지웁니다. 환경 변경·연결 해제 시 이전 계좌의 화면 자료와 실습 기록을 지우므로, 필요한 기록은 먼저 다운로드하세요.

## Streamlit Cloud와 IP

키움은 허용 IP에서 API 인증을 허용하고, 토큰 발급 IP와 조회 요청 IP도 확인합니다. Streamlit Community Cloud의 발신 IP는 예고 없이 바뀔 수 있습니다. 앱의 IP 확인 버튼은 ipify가 관측한 발신 IPv4를 표시하며 인증정보를 전송하지 않습니다. 호스팅 네트워크의 목적지별 경로가 다르면 키움이 관측한 IP와 다를 수 있으므로 인증 오류가 계속되면 호스팅 제공자에게 발신 IP를 확인하세요.

서버 재시작·이동 후 인증 오류가 나면 IP 등록을 다시 확인합니다. 지속적인 접속 안정성이 필요하면 고정 발신 IP를 제공하는 서버로 앱을 옮기는 방식이 적합합니다. 이 변경은 새 서버를 만들거나 비용을 발생시키지 않습니다.

## 연결된 조회 기능

| 기능 | 키움 TR | 처리 기준 |
|---|---|---|
| 토큰 | au10001 | 실전·모의 호스트 분리, 만료 전에 재발급 |
| 잔고 | kt00018 | 연속조회, 국내주식 KRX 평가 기준, 종목별 합산 |
| 예수금 | kt00001 | 일반조회, 실패 시 0원 대신 조회 보류 |
| 체결 내역 | kt00007 | 날짜별 체결내역 조회, 실전 거래소 전체 / 모의 KRX |
| 종목 수급 | ka10059 | 순매수 수량, 단주(주), KRX |
| 시장 수급 | ka10051 | KOSPI·KOSDAQ 종합 행, 순매수 대금(억원), KRX |
| 매수 전 가격 범위 | ka10081 | 매수 당일 이전 원주가 고가·저가 |
| 지수·상대성과 | ka20006 | 공식 명세의 100배 지수를 100으로 나눠 표시 |

현재일 일봉과 수급은 한국시간 18시 전에는 전일까지 요청합니다. 휴일과 자료 누락은 공급기관 응답으로 구분하며 오래된 자료는 기존 검증 규칙에 따라 보류합니다. ka10051은 응답 자체에 일자가 없어 **요청 기준일**로 표시합니다. 종목 일봉·재무자료는 기존 공공데이터포털·OpenDART를 계속 사용합니다.

## 범위와 한계

- 실제 주문·모의 서버 주문을 전송하지 않습니다. 클라이언트는 위 조회 TR만 허용하고 주문 TR은 네트워크 호출 전에 거부합니다. 앱의 매매 연습은 별도 로컬 실습 기록입니다.
- 키움 체결 목록의 시간은 주문시간입니다. 단가×수량으로 거래금액을 계산하고 FIFO 손익은 추정치입니다. 정정·취소나 동일 주문의 서로 다른 체결 합계는 중복 계산을 피하기 위해 분석을 보류합니다.
- 일자별 체결 조회 때문에 긴 기간은 여러 API 호출이 필요합니다. 권한·호출 제한·모의 미지원·연속조회 실패는 이유를 표시하며 일부 응답을 전체 잔고나 전체 체결처럼 표시하지 않습니다.
- 잔고는 국내주식 KRX 평가 기준입니다. 해외주식·퇴직연금 전용 조회는 이번 변경 범위에 포함되지 않습니다.
- 자동 테스트는 합성 응답을 사용합니다. 사용자 키와 등록 IP로 실제 인증·잔고 조회를 완료해야 실서비스 연결 검증이 끝납니다.
